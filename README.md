# Bulging Pouch Checker

Bulging Pouch Checker tracks your transmog collection progress for Patch 12.0.7 cosmetic field pouches and packs sold in Silvermoon City and Umbral Base Camp.

### Features
- **Container Overview**: View total and per-container collection percentages across all 6 pouches and packs.
- **Item Breakdown**: View item icons, quality, slot type, and unlocked/missing status for every cosmetic reward.
- **Filter Views**: Switch between *All Items*, *Missing Only*, and *Collected Only* tabs to quickly see what you still need to collect.
- **Tooltip Progress**: Hover over any pouch item in your bags or at a vendor to see your total progress for that container directly in the item tooltip.
- **Addon Compartment & Menu Support**: Access the window via slash command, the AddOn Manager list, or the Minimap Addon Compartment menu.

### Supported Containers
- **Bulging Twilight Field Pouch** (Triam Dawnsetter — Silvermoon City)
- **Bulging Naga Field Pouch** (Triam Dawnsetter — Silvermoon City)
- **Bulging Amani Field Pouch** (Triam Dawnsetter — Silvermoon City)
- **Bulging Elven Field Pouch** (Triam Dawnsetter — Silvermoon City)
- **Bulging Winter Pack** (Kifaan — Umbral Base Camp)
- **Bulging Ethereal Pack** (Kifaan — Umbral Base Camp)

### Commands
- `/bpc` or `/pouch` — Toggle the main window
- `/bpc summary` — Print collection progress summary to chat
- `/bpc help` — Display available commands
